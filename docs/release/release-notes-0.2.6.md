# CiteNexus 0.2.6

Release date: 2026-11-25. Source: annotated tag `v0.2.6`.

CiteNexus 0.2.6 adds a PanCode pack. The MCP server and the WTF-P companion are unchanged from
0.2.5.

## Changes

- `pancode/` holds a PanCode pack generated by `scripts/prepare_release.py`. Its `mcp.json`
  launches `uvx --from cite-nexus-mcp==0.2.6 cite-nexus-mcp --no-env-file` and declares every
  tool `read`. See [pancode/README.md](https://github.com/PanStudio/pancite/blob/v0.2.6/pancode/README.md).

## Install

```bash
uvx --from cite-nexus-mcp==0.2.6 cite-nexus-mcp --no-env-file
uvx --from cite-nexus-mcp==0.2.6 cite-nexus-wtfp --check
```

See the [changelog](https://github.com/PanStudio/pancite/blob/v0.2.6/CHANGELOG.md) and [documentation](https://github.com/PanStudio/pancite/blob/v0.2.6/README.md) for further details.
